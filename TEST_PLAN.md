# Контрольный список перед публикацией

- [ ] Скачана резервная копия PostgreSQL, проверена возможность восстановления.
- [ ] Сохранена прежняя версия GitHub `index.html` и `server/main.py`.
- [ ] `GET /api/health` возвращает version `9.0-economy` / database `connected`.
- [ ] Старый персонаж: правильные логин, ID, возраст, баланс, Telegram-вход.
- [ ] Старые купленные предприятия появляются как доли, по одной на каждую прежнюю покупку.
- [ ] В магазине покупка еды / воды / кофе уменьшает баланс на цену и повышает соответствующие показатели.
- [ ] Кофейная отрасль увеличивает выручку только после оплаченных покупок.
- [ ] При одном владельце вся доступная собственникам прибыль идёт ему. При двух равных — каждому 50%; при трёх — по 1/3.
- [ ] Работник 16 лет не может устроиться; с 18 доступна биржа и очередь.
- [ ] Если нет финансируемой вакансии, доступна очередь.
- [ ] Совладелец может финансировать зарплатный фонд, нанимать первого по очереди, увольнять. Приоритет очереди сохраняется.
- [ ] Сумма ранее начисленного сотруднику не меняется после увольнения.
- [ ] Премия инициатора появляется только на продажах сверх мощности до найма.
- [ ] Депозит можно создать и частично снять; тело депозита не выдаётся в кредит.
- [ ] Кредит до 30 лет не выдают; при 30+ годах требуют подтверждённый доход и наличие средств фонда.
- [ ] Реальный курс ЖН/₴ не отображается как подтверждённый; реальный вывод выключен.
- [ ] Проверена повторная загрузка страницы, приложение Telegram, экран 320px.

Если видишь неожиданный баланс или потерю аккаунта — останови тест, сохрани сообщения об ошибках и не заменяй БД новой. Восстановление проводится только из собственной копии после анализа причины.
