# НОВАЯ ЖИЗНЬ v10

## Что изменено
- В обложке убраны нарисованные колокольчик и шестерёнка: использована нижняя часть существующего городского фото.
- Добавлены отступы и улучшено отображение на телефоне.
- Информация об учебных заведениях перед поступлением (2 дня; стипендия пока не реализована в сервере).
- Настоящий статус безопасности из PostgreSQL, установка логина и пароля для Telegram-аккаунтов, привязка Telegram к существующему аккаунту при наличии действующей сессии.
- Telegram-авторизация по проверяемому initData осталась без изменений.

## Установка
Замените в GitHub **только** `index.html` и `server/main.py` из этого архива. `server/requirements.txt`, `Procfile`, `railway.json` менять не нужно, если они уже работают. GitHub Pages обновит сайт, Railway автоматически обновит API.

## Важно
НЕ удаляйте PostgreSQL и volume, НЕ меняйте `DATABASE_URL`, НЕ создавайте новый проект Railway. Данные игроков в PostgreSQL сохраняются между деплоями, пока используется та же база. Перед изменением сервера желательно создать резервную копию БД.

Telegram-аккаунт `00000003` уже связан с Telegram ID: попытка привязать этот же Telegram к аккаунту `00000001` будет отклонена, чтобы не потерять или случайно объединить данные. Сначала тестируйте создание пароля для Telegram-аккаунта.
