# НОВАЯ ЖИЗНЬ v9

1. Заменить корневой `index.html` в GitHub.
2. Заменить `server/main.py` и `server/requirements.txt`. Railway Root Directory должен быть `/server`.
3. В Railway создать PostgreSQL **в том же проекте**, что и сервис `new`.
4. В Variables сервиса `new`: `DATABASE_URL` → **Add Reference** → `PostgreSQL` → `DATABASE_URL` (не копировать пароль в GitHub).
5. После деплоя проверить `https://new-production-3d17.up.railway.app/api/health` — ожидается `database: connected`.
6. Для входа Telegram добавить `TELEGRAM_BOT_TOKEN` в Railway Variables (токен от @BotFather; не публиковать). Настроить Mini App URL `https://katasadmin.github.io/new/` у бота.
7. Telegram-вход создаёт отдельный игровой аккаунт по проверенному Telegram ID. **Связь с уже созданным браузерным аккаунтом пока не реализована**; нельзя использовать одновременно оба способа входа для одного персонажа без последующего связывания.
8. Админские API отключены, первая регистрация обычная. Все игровые действия выполняются на сервере и сохраняются в БД.
9. Для безопасности после прежних скриншотов с URL БД рекомендуется сменить пароль PostgreSQL.

## Изменения v9

- Добавлены отступы между описаниями, текстом и кнопками; улучшена читаемость на узких телефонах.
- Админ-панели нет; Telegram Mini App и PostgreSQL остаются в комплекте.
- Изменения внешнего вида находятся в корневом `index.html`; серверные файлы сохранены из v8.
