# НОВАЯ ЖИЗНЬ — исправление экрана и новый интерфейс 9.1

**Что меняется:** исправлена рекурсия `needsCard`, которая вызывала `Maximum call stack size exceeded` на главной. Добавлены оформленные экраны Республики, новая главная страница, навигация по иллюстрированной карте, работа, бизнес, магазин, финансы, раздел «Ещё». Все игровые покупки, начисления и действия с депозитами идут через существующий FastAPI.

**Версия сервера остаётся `9.0-economy`.** Это обновление интерфейса, а не изменение схемы базы данных. Отдельного серверного обновления для исправления ошибки НЕ требуется, если экономика 9.0 уже запущена и `/api/health` отвечает `version: 9.0-economy`, `database: connected`.

## Самый безопасный вариант обновления

1. Сохрани текущие файлы GitHub и резервную копию PostgreSQL. **Не удаляй/не пересоздавай PostgreSQL.**
2. В ветке `main` репозитория `https://github.com/KatasAdmin/new` замени **один файл в корне** — `index.html`.
3. В корне создай папку `assets`, если её нет, и загрузи в неё 5 файлов из этого ZIP: `city.webp`, `cafe.webp`, `factory.webp`, `energy.webp`, `academy.webp`.
4. Нажми **Commit changes** и дождись публикации GitHub Pages.
5. Открой в обычном браузере `https://katasadmin.github.io/new/?v=91` (параметр помогает обойти старый кэш). В Telegram полностью закрой мини-приложение и открой снова.
6. Проверь, что главная, профиль, работа, бизнес, магазин, банк, карта открываются без `Maximum call stack size exceeded`, а ID, возраст и баланс старого персонажа прежние.

`server/` в архиве — совместимый набор версии 9.0 для полного развёртывания, **не нужно повторно заменять его при простом исправлении интерфейса**. Railway Root Directory остаётся `/server`, не меняй `DATABASE_URL` и `TELEGRAM_BOT_TOKEN`.

## Что реально работает, а что ещё нет

Работает на сервере: регистрация, логин и Telegram-авторизация, профиль и образование, товары и реальные *игровые* покупки, доли бизнесов, зарплатные фонды, подача заявок, найм и увольнение через API, внутриигровые депозиты и кредиты по установленным ограничениям.

Карта — **навигация по разделам игры**, а не полноценное передвижение по улицам. Новости — объявления об игровых функциях, не вымышленные действия игроков. Общение и награды пока заглушки. Реальный резерв, курс ЖН→₴, пополнения и вывод **отключены**: макет ранее ошибочно показывал их как готовые, в этой версии этого нет.

Внешняя картинка, вдохновившая дизайн, была концепт-артом. Интерфейс 9.1 отражает её тёмно-синюю стилистику и городские панели, но не является пиксельной копией и не включает неразработанные функции.
